# WCAG Audit

Tanggal: 2026-06-27
Scope: `src/`
Metode: audit source statis + hasil build `dist/`

## Kesimpulan

Belum sesuai WCAG secara penuh. Ada setidaknya satu pelanggaran Level A yang jelas, sehingga situs ini belum bisa diklaim conformant ke WCAG 2.2.

## Temuan

### 1. Page title tidak mendeskripsikan halaman

- Lokasi: `src/layouts/Layout.astro:25`
- Fakta: semua halaman memakai `<title>Hazuli Fidastian</title>`.
- Dampak: halaman `Beranda`, `Proyek`, `Kontak`, dan versi Inggris tidak bisa dibedakan dengan jelas di tab browser, riwayat, bookmark, dan screen reader.
- Kriteria: WCAG 2.2 SC 2.4.2 Page Titled (Level A).

### 2. Label link pergantian bahasa ambigu

- Lokasi: `src/layouts/Layout.astro:36-39`
- Fakta: link locale hanya bertuliskan `id` dan `en`, tanpa label tambahan.
- Dampak: tujuan link kurang jelas bagi sebagian pengguna dan kurang kuat bila dibaca terpisah dari konteks navigasi.
- Kriteria terkait: WCAG 2.2 SC 2.4.4 Link Purpose (In Context) (Level A).
- Catatan: ini borderline; saya menilainya sebagai risiko aksesibilitas yang perlu diperbaiki walau perlu uji manual tambahan untuk menetapkan fail formal.

### 3. Link email bergantung pada JavaScript dan memakai `href="#"`

- Lokasi: `src/components/Mail.astro:5-13`
- Fakta: link email baru bekerja setelah handler JavaScript mengubah `window.location.href`.
- Dampak: perilaku lebih rapuh, sulit dipahami bila script gagal, dan tidak memberi fallback yang setara.
- Kriteria terkait: robust/compatibility. Perlu uji manual tambahan sebelum memetakan ke SC tertentu.

### 4. Link proyek membuka tab baru tanpa penjelasan eksplisit

- Lokasi: `src/pages/proyek.astro:14-15,27` dan `src/pages/en/projects.astro:15-16,29`
- Fakta: link eksternal memakai `target="_blank"` dan hanya diberi ikon panah.
- Dampak: perubahan konteks bisa mengejutkan pengguna pembaca layar dan sebagian pengguna kognitif.
- Kriteria terkait: praktik baik untuk SC 3.2.5 dan teknik H83/G201; bukan blocker Level A/AA yang paling kuat, tetapi sebaiknya dibenahi.

## Yang Sudah Baik

- Bahasa halaman utama sudah ditandai di elemen `<html lang={lang}>` pada `src/layouts/Layout.astro:18`.
- Struktur landmark dasar sudah ada: `header`, `nav`, `main`, `footer`.
- Heading halaman konten sudah cukup jelas pada halaman `Kontak` dan `Proyek`.

## Prioritas Perbaikan

1. Buat title unik per halaman, misalnya `Beranda | Hazuli Fidastian`, `Proyek | Hazuli Fidastian`, `Kontak | Hazuli Fidastian`.
2. Ganti label locale menjadi nama bahasa yang jelas, misalnya `Bahasa Indonesia` dan `English`, plus `lang` yang sesuai pada masing-masing link.
3. Ganti link email menjadi `mailto:` biasa sebagai fallback utama; jika tetap ingin obfuscation, pastikan fallback non-JS tetap berfungsi.
4. Tambahkan penjelasan bahwa link proyek membuka tab baru, misalnya teks tersembunyi untuk screen reader atau label yang eksplisit.
