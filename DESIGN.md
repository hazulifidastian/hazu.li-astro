# Design
Warm editorial layout for a personal developer website in everyday ambient light. It should feel relaxed and human while staying precise and easy to read.
- Warm paper #fbf8f3, dark ink #292823, secondary text #625f57, rules #ded8cf, and forest links #356653.
- Native system sans serif; monospace only for code. No remote font dependency.
- Centered 54rem container with fluid gutters, compact site identity, conversational page titles, open project rows, and an understated footer.
- Content determines height. Project screenshots sit inline with their descriptions; no cards, decorative images, typing animation, or ornamental labels.
- Current navigation underline, strong keyboard focus, and language controls. Narrow screens wrap navigation instead of hiding links.
- Both languages share presentation. Use short color transitions and keep code and tables locally scrollable.
